# 🖼️ Computer Vision - Image Classification

Proyek klasifikasi gambar sederhana menggunakan **OpenCV + Scikit-Learn**.

## Struktur
- `analysis.ipynb` — pipeline lengkap (load → preprocess → train → predict → visualisasi)

## Notes
- Dataset kecil (< 50 gambar/kelas) → gunakan **Augmentation** atau **CNN** untuk hasil lebih baik.
- Model saat ini menggunakan flatten pixel + Random Forest (cukup untuk demo/portfolio).
